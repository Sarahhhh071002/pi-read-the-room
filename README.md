# @fireanon/pi-read-the-room

Always-on operating rules for opencode/pi. Governs tone, delivery, authorization, creative briefs, and stated facts.

## Install

```
pi install npm:@fireanon/pi-read-the-room
```

## What it does

Loads a single always-on skill (`read-the-room`) that shapes every reply: brevity matched to signal, no apology/acknowledgment/restatement filler, requests treated as their own authorization, and a "you're wrong" protocol that defers to live observations over assumptions.

## Configure

No configuration required. Loads automatically on every session once installed.
